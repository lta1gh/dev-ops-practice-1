# Три вещи, чем удобен VSCODE для работы с GIT

1. Скорость: не нужно писать вручную команды git, все делается через графический интерфейс.
2. Удобство: можно видеть изменения в коде, коммитить и пушить прямо из редактора, что экономит время и упрощает процесс работы с репозиторием.
3. Интеграция: VSCODE поддерживает множество расширений для работы с GIT, что позволяет настроить рабочее пространство под свои нужды и повысить продуктивность.

# Одна вещь, которую удобно делать в терминале

1. Быстрое переключение между ветками: в терминале можно использовать команды git checkout или git switch для мгновенного перехода между ветками, что особенно полезно при работе с несколькими задачами одновременно.
